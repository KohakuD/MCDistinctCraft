# DistinctCraft support

Use [GitHub Issues](https://github.com/KohakuD/MCDistinctCraft/issues) for reproducible bugs and accessibility feedback. Choose the form that best matches the report; it asks for the details needed to investigate without requiring medical information.

Before submitting a report:

1. Check that the issue still occurs with the latest DistinctCraft release for the matching Minecraft and NeoForge versions.
2. Temporarily disable unrelated resource packs, or state which pack changes the same texture.
3. Record the selected DistinctCraft profile and the exact block, item, or control involved.
4. Remove usernames, local file paths, server addresses, tokens, and other private information from logs and screenshots.

CurseForge comments may be used for short questions after publication. GitHub Issues remain reserved for reproducible reports and accessibility feedback.
