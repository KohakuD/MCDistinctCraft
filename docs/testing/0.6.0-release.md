# 0.6.0 release QA

Final in-game QA was completed with the target player on 2 September 2026 using Minecraft 26.2, NeoForge 26.2.0.75, DistinctCraft 0.6.0, and optional Jade 26.2.10.

## Profile and UI evidence

- Clear, Monochrome, and Subtle were switched in-game from the DistinctCraft controls and each profile reloaded successfully.
- The three profile screenshots use the same test wall and viewpoint so their contrast and pattern differences can be compared directly.
- The settings screen shows the current profile and optional target-outline control.
- The target-outline screenshot shows the two-tone outline around only the visible looked-at gold ore block.
- Jade remains optional. Its overlay is deliberately present in the outline screenshot and identifies the customized block as vanilla gold ore, confirming that DistinctCraft preserves block identity.
- Earlier target-player feedback led to removal of the redundant second crosshair marker; the block outline alone was judged clearer.

## Packaged and automated QA

- `clean build` passed after the final metadata and screenshot changes.
- The release validator confirms version, author, project URLs, licenses, support files, canonical SVG, PNG exports, screenshot dimensions, JAR metadata, embedded icon, and packaged license/notice files.
- Baseline, profile, UX, coverage, compatibility, locale-parity, registry, transparency, and no-emissive validations passed.
- NeoForge's current `iconFile` metadata is used; DistinctCraft produces no deprecated-logo metadata warning.
- The final client log contains DistinctCraft 0.6.0 and all three profile resource-pack reloads, with no `ERROR` entry or crash report.
- NeoForge logged the expected development-world upgrade notice from DistinctCraft 0.5.0 to 0.6.0 when the existing test world was opened; the world saved and closed normally.
