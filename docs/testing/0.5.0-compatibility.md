# 0.5.0 overlay compatibility tests

DistinctCraft does not use the Jade or WTHIT API. Both mods identify the unchanged vanilla block IDs while DistinctCraft replaces only their visible textures. The overlay mods are optional development-test tools and are not packaged or declared as dependencies.

## Pinned test matrix

| Provider | Version | Minecraft | Loader |
| --- | --- | --- | --- |
| Jade | 26.2.10+neoforge | 26.2 | NeoForge 26.2.0.75 |
| WTHIT | neo-20.0.0 with bad packets neo-0.12.2 | 26.2 | NeoForge 26.2.0.75 |

The official Modrinth downloads and SHA-512 checksums are pinned in `tools/compatibility-mods.json`.

## Switching providers

Jade and WTHIT must not be tested together. Select exactly one provider before using the IDE play button or `runClient`:

```powershell
.\tools\select-compatibility-mod.ps1 jade
.\gradlew.bat runClient

.\tools\select-compatibility-mod.ps1 wthit
.\gradlew.bat runClient
```

The selector downloads verified files into the ignored `run/.compatibility-mods` cache and activates only the selected provider in `run/mods`. Other unrelated development mods are left untouched.

## Manual smoke test

1. Open the existing development world and run `/function distinctcraft:coverage_smoke_test`.
2. Look at every block in the generated three-block-high columns.
3. Confirm the overlay shows the correct vanilla block name for every changed texture.
4. Switch between Subtle, Clear, and Monochrome and confirm the overlay identity does not change.
5. Close Minecraft normally, then verify the recorded run:

```powershell
.\tools\verify-compatibility-log.ps1 jade
.\tools\verify-compatibility-log.ps1 wthit
```

The log check verifies exact Minecraft, NeoForge, and provider versions; mutual exclusion; a loaded DistinctCraft profile; execution of the coverage smoke test; and the absence of error entries or a crash report. Visual tooltip correctness remains a short manual check.

When the same development world is switched from Jade to WTHIT, Minecraft may report and discard Jades saved `jade:max_position_deviation` game-rule value. The verifier recognizes only this exact provider-switch artifact; every other error still fails the test. A fresh WTHIT-only world does not inherit the Jade value.

## Recorded Jade result

- Jade 26.2.10 loaded successfully with DistinctCraft and the Clear profile.
- The coverage smoke test ran in the development world.
- Target-player testing confirmed that Jade displayed the correct vanilla block identity for every changed texture.
- A separate Survival-mode pass confirmed that Jade reported the correct harvesting tools.
- The final Jade log contained the pinned Minecraft, NeoForge, DistinctCraft, and Jade versions with no error entry or crash report.
- No Jade-specific DistinctCraft integration is currently necessary. A future integration must remain optional and disabled by default.

## Known WTHIT startup warnings

WTHIT 20.0.0, its `waila` compatibility mod ID, and bad packets 0.12.2 currently declare the deprecated NeoForge `logoFile` metadata property. NeoForge shows three non-fatal upstream warnings before the main menu. They do not originate in DistinctCraft and do not prevent the compatibility test; the third-party JARs are left unmodified.

## Recorded WTHIT result

- WTHIT 20.0.0 and bad packets 0.12.2 loaded successfully with DistinctCraft and the Clear profile while Jade was absent.
- The coverage smoke test ran in the existing development world.
- Target-player testing confirmed correct overlay behavior for the changed blocks before switching the environment back to Jade.
- The only startup notices were the three known upstream `logoFile` deprecation warnings described above.
