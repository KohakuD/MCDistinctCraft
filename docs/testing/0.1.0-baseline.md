# 0.1.0 Baseline Test Notes

## Automated smoke checks

Run `.\gradlew.bat validateBaselineResources` or the full `.\gradlew.bat build`.

The check covers:

- presence and 16 x 16 dimensions of andesite, gravel, iron ore, and coal ore textures;
- absence of a stone override, preserving the vanilla texture as the reference baseline;
- coverage of dirt plus all five baseline blocks in the smoke-test function;
- PNG readability;
- identical translation-key sets in `en_us`, `de_de`, and `nl_nl`.

## In-game visual smoke test

1. Start the development client with `.\gradlew.bat runClient`.
2. Create a Creative world with cheats enabled in daylight with smooth lighting enabled.
3. Run `/function distinctcraft:baseline_smoke_test` to create the checked-in test wall.
4. Confirm that every column is three blocks high and the order is dirt, vanilla stone, andesite, gravel, iron ore, and coal ore.
5. Use dirt as the natural-color contrast reference while comparing the five baseline blocks.
6. Check the wall at 2, 8, and 16 blocks of distance, then repeat in a dim cave.
7. Temporarily reduce display saturation to zero and confirm that every baseline block remains distinguishable by pattern and luminance.

## Target-player session

### 2026-08-31 / Initial world review

- Stone, andesite, gravel, iron ore, and coal ore were placed together in a daylight world and inspected across a naturally exposed cave wall.
- The ore symbols and the general idea of a deliberately designed stone texture were received positively.
- The first stone texture was too dominant over large surfaces: its diagonal bands joined into chevrons and a chaotic herringbone pattern across cave walls.
- Requested change: remove the custom stone treatment and retain Minecraft's original stone texture.
- Applied change: the stone override and its generator/localization entries were removed. Automated validation prevents it from being reintroduced accidentally.
