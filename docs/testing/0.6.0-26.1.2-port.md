# DistinctCraft 0.6.0 / Minecraft 26.1.2 port

## Target

- Minecraft 26.1.2
- NeoForge 26.1.2.71 or newer for Minecraft 26.1.2
- Java 25
- Client-side only

## Port changes

- Kept the DistinctCraft feature version at 0.6.0 and added `mc26.1.2` to the artifact filename.
- Adapted the custom target-outline callback to the Minecraft 26.1.2 rendering API.
- Changed all bundled accessibility profiles from resource-pack format 88.0 to 84.0.
- Pinned optional compatibility-test downloads to Jade 26.1.10 and WTHIT 19.0.1 with bad packets 0.12.2.

## Verification

- `gradlew build` completes with all resource, locale, coverage, compatibility, licensing, branding, and packaged-JAR validators.
- The packaged metadata requires exactly Minecraft 26.1.2 and NeoForge 26.1.2.71 or newer.
- The packaged mod version remains 0.6.0.
- The generated artifact is named `distinctcraft-0.6.0-mc26.1.2.jar`.
- The target player confirmed the Minecraft 26.1.2 build in game before publication preparation.
