## Description

DistinctCraft is a client-side accessibility mod for players who benefit from clearer shape, pattern, and contrast differences. It provides three built-in visual profiles—Clear, Subtle, and Monochrome—for vanilla ores, andesite, gravel, and matching ore-drop items. Vanilla stone remains unchanged as a neutral reference.

The profiles use static resource-pack textures. DistinctCraft does not scan the world, reveal hidden blocks, add emissive ore glow, or change gameplay. No server installation is required.

### Features

- Clear, Subtle, and Monochrome accessibility profiles
- In-game settings and keyboard shortcuts for fast profile changes
- Optional high-contrast outline for the block currently under the crosshair
- Coverage for standard Overworld ore variants, Nether quartz, and Nether gold
- Matching primary ore-drop item textures
- English, German, and Dutch interface text
- Compatible with standard resource packs; higher-priority packs may override DistinctCraft textures
- Jade and WTHIT remain optional; neither is required

## Installation

1. Install Minecraft 26.2 with NeoForge 26.2.0.75 or a compatible newer NeoForge build for Minecraft 26.2.
2. Place the DistinctCraft JAR in the client `mods` folder.
3. Start Minecraft. DistinctCraft is client-side only and is not required on a server.
4. Open the DistinctCraft settings screen to choose Clear, Subtle, or Monochrome.

Requires Java 25 through the Minecraft launcher runtime. OptiFine is not required.
